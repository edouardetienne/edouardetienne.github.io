# Defect lifecycle
## Bug life cycle states
### Core workflow
- **New** - tester reports a bug => clear, complete bug report
- **Active** - developer owns it => bug is acknowledged and actively worked on by a developer
- **Resolved** - fix or decision made => back to tester to verify the resolution is correct
- **Closed** - verified and done => resolution is confirmed

## Resolution types
- **Fixed** - bug reproduced and fixed
- **Duplicate** - bug already reported in another ticket
- **Cannot reproduce** - bug could not be reproduced
- **Won't fix** - decision not to fix for some reason
- **Not a bug** - reported behaviour is actually working as intended
- **Known issue** - bug is real and acknowledged, but fix not yet scheduled
- **Deferred** - bug is valid but postponed to a future release
