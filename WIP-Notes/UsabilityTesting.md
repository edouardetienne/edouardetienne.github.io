# Usability testing
Empathy with the user

## Think-aloud protocol
a method to understand the user's mental model and internal dialogue while using the application
=> user says whatever comes in mind while using the application, while an observer listen and takes notes (and does nothing else)

identification of 2 types of issues:
- **defects** = a flaw in the software causing it to behave in an incorrect/unexpected way, preventing it from meeting the requirements => objective failure
- **friction point** = an element of the user experience, that is confusing, inefficient or annoying, regardless of the technical quality of the software

## WCAG basics & web accessibility
accessibility = it is for everyone
=> inclusive design
**WCAG** = Web Content Accessibility Guidelines
### P.O.U.R. framework
- **P**erceivable - all users must be able to perceive the information being presented (ex: ALT text for images)
- **O**perable - all users must be able to operate the interface (ex: website accessible with mouse AND keyboard)
- **U**nderstable - content must be clear and the interface must behave predictably (ex: providing message about input)
- **R**obust - content must work reliably across browsers, devices and assistive technologies
